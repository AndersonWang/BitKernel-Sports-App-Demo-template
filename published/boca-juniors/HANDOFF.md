Framework v1.1.0 · updated 6 Nov 2026 · team package for **Boca Juniors (Club Atlético Boca Juniors)** · owner Anderson Wang, BitKernel Design

## 3. How to update it

**Content (no code):** Configure, see CONFIGURATION.md. Changes stay in your browser; send them with Export config or Download offline copy.

**Built-in content (AI agent or developer, needs the source package):**

| To change | Where in the source |
|---|---|
| Boca photos and videos | `public/assets/themes/boca-juniors-light/<same path as the shipped file>`, listed in `src/tokens/theme-assets.json` (`stills` lists videos Boca has no copy of) |
| Club text, find/replace and exact swaps, cup rule | `src/tokens/theme-text.json` (theme pack) and `src/editions/boca/theme-text.json` (Boca-only copy) |
| Squad, players outside the line-up, league table, opening colours | `src/tokens/theme-squads.json`, `theme-tables.json`, `theme-launch.json` |
| Colours | `src/tokens/semantics.json`, mode "Boca Juniors (Light)" |
| This guide | `src/editions/boca/HANDOFF.md` (README and CONFIGURATION are generated by `scripts/docs.mjs`) |

Then `npm run build:boca`, check the changed screens, publish `dist-boca/` to the online link (more than 255 files: two publishes), make the offline zip, and add a line to the change log below. In the template, Boca's photos ship as one packed file (`assets/themes/boca-juniors-light.pack.js`); the template build makes it.

## 4. Open questions for the club

- **Squad and coach:** names are placeholders per Conor; confirm the current squad and coach.
- **League table:** shows 15 clubs with placeholder points; the Liga Profesional has 30 clubs in two zones.
- **Videos:** no Boca live room, live match or clip video yet. Send one and it replaces the photos.
- **Live room photos** are 524 to 686 px tall, slightly soft on a phone. Larger versions would look sharper.
- **Real people:** Riquelme (live room title), current players and the star photos need the club's permission before any showing outside a pitch.
- **Figma:** the Boca colour mode isn't in Figma yet.
